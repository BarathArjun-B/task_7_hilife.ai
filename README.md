# Employee Clock In / Clock Out Timer

This project is a responsive Employee Clock In / Clock Out Timer Management Web Application developed using:

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

The application allows multiple users to:
- create accounts
- login/logout
- track work sessions
- maintain persistent timers
- manage individual employee work durations

The timer continues running even after:
- page refresh
- logout
- browser close
- tab switching

The timer only stops when the user clicks:
```txt
Clock Out
